// Row 8 of every 6x8 cell is blank (line spacing), column 6 is blank.
// Re-purposed ASCII codes (the game never needs the originals):
//   $  -> star        &  -> solid block     @  -> down arrow
//   [  -> left arrow  ]  -> right arrow     ^  -> up arrow
//   \  -> music note  #  -> sharp sign
