# Part A: controls and feedback

Part A's layers (pointer, aim dots, stance readout, power / spin meters, swipe trail)
switched off and on. In the 3-D view Part A draws only the pointer; its speed,
power and spin values are shown there by Part D's panel. In the top-down view it
draws its own readouts.
